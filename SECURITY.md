# Seguridad

Este repositorio es público. No incluir credenciales, tokens, datos personales,
URLs internas ni configuración de staging en issues, capturas o pull requests.
Las fixtures deben contener únicamente datos sintéticos.

Para contactar a Rentennials, usar https://www.rentennials.app/contact.
El canal especializado de reporte de vulnerabilidades está pendiente de
definición. No publicar detalles de una vulnerabilidad ni datos sensibles
en un issue público.

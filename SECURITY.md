# Seguridad

Este repositorio es público. No incluir credenciales, tokens, datos personales,
URLs internas ni configuración de staging en issues, capturas o pull requests.
Las fixtures deben contener únicamente datos sintéticos.

El canal privado para reportar vulnerabilidades está pendiente de definición
por Rentennials. No publicar detalles de una vulnerabilidad ni datos sensibles
en un issue público. Este archivo se actualizará con el canal confirmado.
